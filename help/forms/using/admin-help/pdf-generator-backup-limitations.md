# Sauvegardes limitées de PDF Generator {#pdf-generator-backup-limitations}

Le répertoire temporaire utilisé par PDF Generator pour convertir les fichiers ne peut pas être sauvegardé. Même si le service est restauré correctement, les données peuvent être perdues, car PDF Generator examine et efface le contenu du répertoire temporaire à intervalles définis.
